[2203] Working rules:
[2204] Trunk-based development; small pull requests; CI must be green to merge.
[2205] Member 1 reviews every change to prisma/ and the contract package (D17).
[2206] A phase is done only when its acceptance criteria pass on staging, not when the code is written.

[2208] If a phase overruns by more than an hour, cut from the list in 6.6 rather than borrowing from Phase 9.
